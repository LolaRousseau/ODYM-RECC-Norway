# ODYM-RECC-Norway
A streamlined version of the original ODYM-RECC, for Norway.

This code was used for the following publication: "Retrofitting Norwegian residential buildings: an archetype-based dynamic stock model" by Rousseau, L. S. A., Amini, S., Akin, S., & Hertwich, E. G. (Link will be added upon publication).

## Description
ODYM-RECC-Norway is a modified version of the Open Dynamic Material Systems Model for Resource Efficiency and Climate Change Mitigation (ODYM-RECC) originally developed by Pauliuk, Fishman, et al. (2021). ODYM-RECC was streamlined in Akin et al. (2025) to exclude vehicle-related model, and the energy demands associated with demolition and waste treatment. ODYM-RECC-Norway was derived from that streamlined version to model building retrofit in Norway including adoption of heat pumps and lifetime extension.

Links to original ODYM-RECC model:
- Pauliuk, Fishman, et al. (2021) - https://doi.org/10.1111/jiec.13023
- RECC-ODYM - https://github.com/IndEcol/RECC-ODYM
- Latest info and documentation - https://www.industrialecology.uni-freiburg.de/odym-recc

Links to streamlined version of ODYM-RECC, for Western Asia and Northern Africa:
- Akin et al. (2025) - https://doi.org/10.1016/j.scs.2025.106351
- ODYM-RECC-WN - https://github.com/shnkn/ODYM-RECC-WN

For lifetime extension, we used the Dynamic Lifetime Model (DLM) framework by Krych (2024): 
- Dynamic Lifetime Model (DLM) - https://github.com/NTNU-IndEcol/dynamic_lifetime_model

## Setup
To use ODYM-RECC-Norway, one needs the following frameworks and database:
- ODYM - https://github.com/IndEcol/ODYM
- Dynamic Lifetime Model (DLM) - https://github.com/NTNU-IndEcol/dynamic_lifetime_model
- The database available on Zenodo - https://doi.org/10.5281/zenodo.19886444
